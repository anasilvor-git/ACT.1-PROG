# Analisis_de_componetes

## descripcion
Esta sección comprende el análisis de los componentes biológicos y químicos presentes en muestras de agua y sedimento provenientes de una Estación Depuradora de Aguas Residuales (EDAR) y del arroyo receptor.

## Objetivo
Evaluar la biomasa, identificar posibles contaminantes mediante HPLC y caracterizar las comunidades microbianas mediante extracción de ADN y secuenciación del gen 16S rRNA.

## Líneas de análisis
- **Biomasa:** determinación mediante peso seco.
- **HPLC:** identificación y cuantificación de compuestos químicos.
- **ADN:** extracción, purificación y evaluación de calidad.
- **16S rRNA:** caracterización taxonómica de comunidades bacterianas.

## Procesamiento bioinformático
Se contempla el uso de QIIME 2, DADA2, BLAST y R para el procesamiento, análisis e interpretación de los datos.

## Datos
Se incluyen archivos CSV con datos simulados para fines académicos, destinados a la organización y práctica de análisis bioinformáticos.
